Preparar Ambiente\n\n```bash\n# Verificar versão do Node\nnode --version  # v18+ recomendado\n\n# Instalar dependências\nnpm ci  # Use ci ao invés de install em produção\n\n# Build otimizado\nnpm run build\n\n# Verificar build\nls -la dist/\n```\n\n### 2. Configurar Variáveis de Ambiente\n\n**Arquivo: `.env.production`**\n```env\n# Supabase\nVITE_SUPABASE_URL=https://your-project.supabase.co\nVITE_SUPABASE_ANON_KEY=your-production-anon-key\n\n# API\nVITE_API_URL=https://api.bateumz.online\n\n# Analytics\nVITE_ANALYTICS_ID=your-analytics-id\n\n# Sentry (Error tracking)\nVITE_SENTRY_DSN=https://your-sentry-dsn\n```\n\n### 3. Deploy Frontend\n\n#### Opção A: Vercel (Recomendado)\n```bash\n# Instalar Vercel CLI\nnpm i -g vercel\n\n# Deploy\nvercel --prod\n\n# Verificar deployment\nvercel ls\n```\n\n#### Opção B: Netlify\n```bash\n# Instalar Netlify CLI\nnpm i -g netlify-cli\n\n# Deploy\nnetlify deploy --prod --dir=dist\n```\n\n#### Opção C: Docker (Self-hosted)\n```bash\n# Build image\ndocker build -t bateumz:latest .\n\n# Run container\ndocker run -p 3000:80 bateumz:latest\n```\n\n### 4. Deploy Supabase\n\n```bash\n# Link ao projeto Supabase\nsupabase link --project-ref your-project-ref\n\n# Deploy migrações\nsupabase migration up\n\n# Deploy Edge Functions\nsupabase functions deploy calculate-world-cup-points\nsupabase functions deploy award-engagement-points\n\n# Verificar status\nsupabase status\n```\n\n### 5. Configurar DNS\n\n```\nDomínio: bateumz.online\n\nRegistros DNS:\n- A: 76.76.19.165 (Vercel/seu-host)\n- CNAME: cname.vercel-dns.com (se usar Vercel)\n- MX: mail.bateumz.online (para emails)\n- TXT: v=spf1 include:sendgrid.net ~all (SPF)\n```\n\n### 6. Configurar SSL/TLS\n\n```bash\n# Vercel/Netlify configuram automaticamente\n# Para self-hosted:\n\n# Usar Let's Encrypt\nsudo certbot certonly --standalone -d bateumz.online\n\n# Renovação automática\nsudo certbot renew --quiet --no-self-upgrade\n```\n\n---\n\n## 📊 Monitoramento Pós-Deployment\n\n### 1.
